## 🚀 Featured Projects

### 📶 [WifiTracker](https://github.com/mohiuddinramzan/WifiTracker)
Android app that tracks how long your device stays connected to WiFi — daily,
weekly, monthly, and yearly breakdowns. Digital Wellbeing-style UI, fully offline,
built with Jetpack Compose.

### 📝 [TextExtractor](https://github.com/mohiuddinramzan/TextExtractor)
Free, open-source Android app that extracts text from photos and gallery images.
Supports English and Bengali via Tesseract OCR, works fully offline after a
one-time language download.

### 😅 [Bekar Meter](https://github.com/mohiuddinramzan/bekar-meter)
A fun productivity & motivation web app — track your "unemployment level," take
daily challenges, generate funny excuses, and share your Bekar Card. Built with
HTML, CSS & JavaScript.
